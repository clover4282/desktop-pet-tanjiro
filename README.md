# 치비 데스크톱 펫 (Chibi Desktop Pet for Windows)

Windows 바탕화면과 열려 있는 창 위를 돌아다니는 초경량 단일 `.exe` 데스크톱 펫입니다.
별도 설치 없이 `dist/ChibiDesktopPet.exe` 파일 하나만 윈도우 PC로 복사해 더블클릭하면 바로 실행됩니다.

## 포함 캐릭터 (총 6종 · 중복 소환 금지)

- **망곰**: 망그러진 곰 (딸기 케이크 & 하트)
- **귀멸의 칼날 (5인)**:
  - **카마도 탄지로** (물의 호흡 파도 & 물방울)
  - **렌고쿠 쿄쥬로** (도시락 & 불꽃 충격파)
  - **아가츠마 젠이츠** (번개의 호흡 & 벽력일섬 지그재그)
  - **하시비라 이노스케** (새우튀김 & 호와호와 핑크 구름)
  - **아카자** (파괴살·나침 눈꽃 문양)

## 주요 기능 및 조작법

- **실행 시 오프닝**: 작업표시줄 오른쪽 위에 **망곰**이 나타나고, 회전하는 프로펠러 집게가 **탄지로**를 내려 망곰 머리 위에 올려줍니다.
- **중복 소환 금지**: 이미 화면에 나와 있는 캐릭터는 메뉴에서 `(소환됨)`으로 비활성화되며, 랜덤/전원 소환에서도 중복 생성되지 않습니다.
- **전용 옆모습 걷기 & 좌/우 벽타기 애니메이션**:
  - 6종 모두 전용 **옆모습 걷기 2프레임**과 **옆모습 벽타기 2프레임** 스프라이트를 적용했습니다.
  - 창의 왼쪽 벽을 탈 때는 오른쪽을 보고, 오른쪽 벽을 탈 때는 왼쪽을 보고 손발을 교차하며 리듬감 있게 올라갑니다.
  - 창이나 벽에서 **내려올 때는 벽을 타지 않고 항상 웅크린 뒤 포물선으로 뛰어내립니다**.
  - **머리 위에 다른 캐릭터가 올라가 있을 때는 벽을 타거나 뛰어내리지 않습니다**.
- **좌클릭 (쓰다듬기)**: 각 캐릭터의 전용 소품·특별 리액션과 파티클 효과가 재생됩니다.
- **문지르기 (마우스 커서로 좌우 쓱쓱 문지르기)**: 캐릭터별 고유 오라·표정·파티클 반응이 나타납니다.
- **드래그 & 드롭**: 다른 캐릭터 머리 위에 놓으면 쌓이고, 공중에 놓으면 캐릭터별 고유 낙하·착지 애니메이션이 재생됩니다.
- **전용 앱 아이콘 내장**: 망곰 + 프로펠러 디자인의 다중 해상도 `.ico` (16~256px)가 `.exe` 및 시스템 트레이에 내장되어 있습니다.

## 직접 빌드하기 (Go 1.24+)

```bash
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-H=windowsgui -s -w" -o dist/ChibiDesktopPet.exe ./cmd/chibipet
```
